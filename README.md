# nocodo

nocodo is a set of narrow, close-to-deterministic agents that build data tools for non-technical users. Each agent owns one part of the software lifecycle and produces typed specs, not code; deterministic Rust code turns those specs into real artifacts such as SQL migrations, and a prebuilt runtime runs them. Users never need a Rust toolchain.

- [`PRD.md`](PRD.md): what Experiment 1 is testing and why.
- [`AGENTS.md`](AGENTS.md): rules and crate boundaries for coding agents.
- [`epics/`](epics/): the step-by-step build plan, one epic at a time.
